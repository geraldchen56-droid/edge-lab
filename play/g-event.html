Event Contracts

Skill: Bayesian updating, quoting in probabilityPrediction-market desks

A YES contract pays 100 if the event happens and 0 if not, so its fair price in cents equals the probability. You start from a base rate, update with the news using odds × LR, then quote a two-sided market. Some traders already know the answer.

Shorthand
  • Price in cents = probability. Edge buying YES = p − ask.
  • Informed traders only hit you when you're wrong. Width must cover them.
  • Near 0% or 100%, quote tighter in cents because there is less room to be wrong.
