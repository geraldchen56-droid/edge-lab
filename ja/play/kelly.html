ケリー基準のベットサイズ

使う場面：ハイ・オア・ロー、ベッティングボード、ポーカーの資金管理、ポジションサイズ

プラス期待値だけでは不十分です。賭けすぎれば、連敗で資金が尽きます。ケリー基準は長期的な成長を最大化する資金の割合を選びます。勝率p、ネットオッズb（1賭けて勝てばb）とすると：

f* = (b·p − (1 − p)) / b = エッジ / オッズ 1対1なら：f* = 2p − 1

ケリーの2倍を賭けると長期成長はほぼゼロ、それ以上だと、どの賭けもプラス期待値なのに資金が減っていきます。多くのプロはハーフケリーで賭けます。自分のpは推定値にすぎないからです。

仕組み：f* = (b·p − q) ÷ b の読み方
f*現在の資金のうち賭ける割合。星印は最適値であることを示します。
p賭けに勝つ確率。
q = 1 − p負ける確率。
bネットオッズ：勝ったときの1賭けあたりの利益。1対1なら b = 1。小数オッズdからは b = d − 1。
b·p − q1賭けあたりの期待値：確率pでbを得て、確率qで1を失う。これがあなたのエッジです。
÷ b振れ幅の大きい大穴の賭けでは縮小します。だから結果はエッジをオッズで割ったものになります。

なぜ単純に期待値を最大化しないのか？

期待値の最大化は、プラス期待値の賭けすべてに全額を賭けろと言い、最初の負けで資金はゼロになります。資産は足し算ではなく掛け算で複利的に増えます。+50%の後に−50%だと、1.5 × 0.5 = 0.75 になってしまいます。そこでケリーは平均成長率、つまり各賭けの資産倍率の対数の期待値を最大化します：

g(f) = p · ln(1 + f·b) + q · ln(1 − f)

ここで ln(1 + f·b) は勝ったときの資産倍率の対数、ln(1 − f) は負けたときの倍率の対数です。gの傾きをゼロと置くと p·b ÷ (1 + f·b) = q ÷ (1 − f)、fについて解くと f* = (b·p − q) ÷ b。

例：p = 0.55、b = 1 → f* = 0.10。1回あたりの成長 = 0.55 · ln 1.1 + 0.45 · ln 0.9 = 0.0524 − 0.0474 = 0.0050。1回あたり約0.5%が複利で効いてきます。

覚え方
  • 1対1ならエッジ分を賭ける。勝率55% → 資金の10%。
  • マイナス期待値 → 0を賭ける。ケリーは負ける提案に賭けろとは決して言いません。
  • ハーフケリーは成長の約75%を保ちつつ、ドローダウンをずっと小さくします。
