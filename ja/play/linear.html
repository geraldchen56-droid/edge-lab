線形性とばらつき

使う場面：サイコロ、トレーディングゲーム、カードゲーム

和の期待値は期待値の和に等しくなります。各部分が独立でなくても成り立つので、サイコロ2個の値付けで36通りを書き出す必要はありません。

E[X + Y] = E[X] + E[Y]

分散が足し算できるのは、各部分が独立なときだけです。そのためσは部分の数の平方根で増えます。サイコロ10個の期待値は1個の10倍ですが、ばらつきは約3.2倍にすぎません。だから和は釣り鐘型になり、気配の幅はフェアバリューより緩やかに広げるべきなのです。

σ（n個の独立な和）= σ₁ · √n
仕組み：期待値は常に足せるのに、ばらつきはそうでない理由

E[X + Y] = E[X] + E[Y] の読み方

E[ · ]かっこ内の量の「期待値」。
X, Y2つの確率変数。たとえばサイコロ1とサイコロ2。
X + Y新しい確率変数：毎回の2つの合計。

なぜ常に成り立つのか。平均とは「全部足してから割る」ことで、足す順番は関係ありません。サイコロ2個を600回振ったとき、すべての和の総計は、サイコロ1の列の合計とサイコロ2の列の合計を足したものに等しくなります。依存関係が変えるのは同じ行にどの値が並ぶかであって、各列の合計ではありません。

Var(X + Y) = Var(X) + Var(Y) + 2·Cov(X, Y) の読み方

Cov(X, Y)共分散：XとYが一緒に大きくなりやすい（正）か、逆に動く（負）か、無関係（ゼロ）か。(X − μₓ)(Y − μᵧ) の平均です。
独立一方を知っても他方について何も分からない状態。このとき Cov = 0 で、分散はそのまま足せます。

√n はどこから来るのか

分散σ₁²を持つ独立なコピーをn個足します。分散を足すと n·σ₁² なので σ = √(n·σ₁²) = σ₁·√n。サイコロ10個なら 1.71 × √10 ≈ 5.40 で、期待値は35です。金融ではこれが分散投資が効く理由です。完全には相関しない多くの資産を持つと、期待リターンはリスクより速く増えます。

覚え方
  • 和 → 期待値を足す。サイコロn個 = 3.5n。戻さないカードn枚 = 7n。
  • ばらつき → √n。サイコロn個のσ ≈ 1.71√n。結果のおよそ95%は2σ以内に収まります。
  • 分かっている部分 → そのまま代入。1個が5なら、サイコロ2個のフェアは 5 + 3.5 = 8.5。
  • 戻さない場合：未知のカードの平均は7ではなく残りのデッキの平均。
