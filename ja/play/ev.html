ブリーフィング · スタディホール

期待値

使う場面：すべてのゲーム

期待値とは、ランダムな利得の長期的な平均です。すべての結果を挙げ、それぞれに確率を掛けて足し合わせます。

EV = Σ pᵢ · xᵢ

分散は結果が平均の周りにどれだけ散らばるかを測り、標準偏差（σ）はその平方根です。期待値は取引するかどうかを、σは気配の幅と賭け金の大きさを教えてくれます。

Var = Σ pᵢ · (xᵢ − EV)² = E[X²] − EV²
仕組み：期待値と分散のすべての記号

EV = Σ pᵢ · xᵢ の読み方

X確率変数：サイコロの目のように、事象が起きるまで分からない数。
i起こりうる各結果のラベル。1、2、3……と数えます。サイコロならiは1から6。
xᵢ結果iの利得。サイコロなら x₁ = 1、x₂ = 2 … x₆ = 6。
pᵢ結果iの確率で、0から1の間。すべてのpᵢを足すとちょうど1になります。
pᵢ · xᵢその結果が平均に寄与する分。
Σギリシャ文字の大文字シグマで、「すべてのiについて足す」という意味。結果ごとに同じことをして、足し合わせます。
EV、E[X]、μ同じ答えの3つの呼び名。他の式の中で使うときは、ふつうμ（ミュー）と書きます。

なぜpを掛けるのか？サイコロを600回振るとします。各目がおよそ100回ずつ出るので、合計は約 100·1 + 100·2 + … + 100·6 = 2,100、平均は 2,100 ÷ 600 = 3.5。各回数を600で割ると確率になり、(1/6)·1 + (1/6)·2 + … + (1/6)·6 となります。期待値は、各結果を起こる頻度に応じて数えるふつうの平均なのです。

Var(X) = Σ pᵢ · (xᵢ − μ)² の読み方

μ上で求めた期待値：結果の中心。
xᵢ − μ偏差：結果iが中心からどれだけ離れているか。マイナスは中心より下。
( … )²偏差の2乗。2乗するとすべての距離が正になり、大きな外れを小さな外れよりずっと重く罰します（3外れれば9、1外れれば1）。
pᵢ · ( … )²各偏差の2乗を、起こる頻度で重み付けしたもの。
Σすべて足します。分散は中心からの距離の2乗の平均です。
σ = √Var標準偏差（小文字のシグマ）。平方根を取ると2乗が打ち消され、利得と同じ単位（目、ドル）に戻るので、期待値と比べられます。

なぜ偏差をそのまま平均せずに2乗するのか？ふつうの平均偏差は常にちょうどゼロだからです。中心はつり合いの点として定義されるので、上と下の外れが打ち消し合います。下の表がその証明で、p·(x − μ) の列は必ず0になります。絶対値 |x − μ| を使うこともできますが、2乗には後々すべてをうまく働かせる性質があります。独立な量の分散は足し算できるのです。√nルールはここから生まれます。

近道 E[X²] − μ² が成り立つ理由。E[X²] は「利得の2乗の平均」、つまり Σ pᵢxᵢ² です。(x − μ)² = x² − 2μx + μ² と展開し、各項を平均すると E[X²] − 2μ·E[X] + μ² = E[X²] − 2μ² + μ² = E[X²] − μ²。サイコロなら 91/6 − 3.5² = 15.17 − 12.25 = 2.92。

  • 確率の合計は1でなければならない。毎回まずこれを確認。
