线性与离散度

用于：骰子做市、交易游戏、卡牌游戏

和的期望值等于期望值的和。即使各部分相互依赖也成立，所以给两颗骰子定价时，你永远不必列出 36 种结果。

E[X + Y] = E[X] + E[Y]

只有各部分独立时，方差才能相加。所以 σ 按部分数量的平方根增长：十颗骰子的期望是一颗的十倍，但离散度只有约 3.2 倍。这就是为什么和的分布看起来像钟形曲线，也是为什么你的报价宽度应该比公允价值增长得慢。

σ(n 个独立量之和) = σ₁ · √n
原理：为什么期望总能相加，而离散度不能

理解 E[X + Y] = E[X] + E[Y]

E[ · ]括号里的东西的“期望值”。
X, Y两个随机量，比如第 1 颗和第 2 颗骰子。
X + Y一个新的随机量：每次掷骰的两者之和。

为什么它总是成立。平均数就是“全部加起来再除”，加的顺序无关紧要。掷两颗骰子 600 次，所有和的总数等于第 1 颗那一列的总数加第 2 颗那一列的总数。依赖关系改变的是哪些值出现在同一行，而不是每一列加起来是多少。

理解 Var(X + Y) = Var(X) + Var(Y) + 2·Cov(X, Y)

Cov(X, Y)协方差：X 和 Y 是倾向于同时偏高（正），朝相反方向变动（负），还是互不相干（零）？它是 (X − μₓ)(Y − μᵧ) 的平均值。
独立知道一个对另一个毫无信息。此时 Cov = 0，方差直接相加。
设定关系方差σ
两颗不同的骰子，X + Y独立，Cov = 02.92 + 2.92 = 5.832.42
同一颗骰子算两次，X + X完全同向4 × 2.92 = 11.673.42
X + (7 − X)完全反向00

最后一行是对冲：两个有风险的头寸，误差恰好抵消。三种设定的期望值都是 7，只有离散度不同。

√n 从哪里来

把 n 个独立的复制品相加，每个方差为 σ₁²。方差相加得 n·σ₁²，所以 σ = √(n·σ₁²) = σ₁·√n。十颗骰子：1.71 × √10 ≈ 5.40，而期望值是 35。在金融里，这就是分散投资有效的原因：持有许多并非完全相关的资产，预期收益的增长快于风险的增长。

速记
  • 求和 → 期望相加。n 颗骰子 = 3.5n。n 张不放回的牌 = 7n。
  • 离散度 → √n。n 颗骰子 σ ≈ 1.71√n。大约 95% 的结果落在 2σ 以内。
  • 已知部分 → 直接代入。一颗骰子是 5：两颗骰子的公允价值是 5 + 3.5 = 8.5。
  • 不放回时：未知牌的平均值是剩余牌堆的平均值，而不是 7。
